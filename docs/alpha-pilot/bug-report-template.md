# Bug Report Template

Use this when something breaks, looks wrong, or behaves differently than expected.

## Required Fields

- Reporter:
- Date/time:
- Role: Owner / Employee / Platform Admin / Operator
- Workspace/company:
- Environment: Local / Deployed alpha
- Browser and version:
- Device/OS:
- Route or feature:
- User account type used: Cognito / Pilot fallback / Platform Admin
- Expected behavior:
- Actual behavior:
- Steps to reproduce:
- Frequency: Once / Sometimes / Always
- Severity: Blocker / High / Medium / Low
- Screenshot or screen recording available: Yes / No
- Console error text if visible:
- Network request/status if visible:
- Whether refreshing fixes it:
- Whether signing out/in fixes it:

## Privacy Note

Do not paste bearer tokens, database URLs, passwords, Cognito secrets, platform admin identities, invite token hashes, or real customer private data into the bug report.

## Suggested Format

```text
Role:
Environment:
Route:
Expected:
Actual:
Steps:
Severity:
Console/network:
Notes:
```
