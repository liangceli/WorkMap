# WorkMap Asset Staging Guide

This folder documents where manually selected art assets should be placed in the web app public asset tree.

## Target Asset Folders

- `apps/web/public/assets/limezu/modern-office/tilesets/`
  - Put Modern Office tilesets here.
  - Example: `Modern_Office_32x32.png`.
- `apps/web/public/assets/limezu/modern-office/objects/`
  - Put office furniture and object assets here.
- `apps/web/public/assets/limezu/modern-office/examples/`
  - Put Modern Office example images or reference maps here.
- `apps/web/public/assets/avatars/presets/`
  - Put temporary complete character sprite sheets here.
  - Example: `Farmer_2_No_Hat_32x32.png`.
- `apps/web/public/assets/avatars/bodies/`
  - Put body/base avatar layers here.
  - Example: `Body_2_32x32.png`.
- `apps/web/public/assets/avatars/animations/`
  - Put later animation layers here.
  - Use subfolders for `body`, `hair`, `tops`, `bottoms`, and `presets`.
- `apps/web/public/assets/temporary-objects/`
  - Put neutral temporary objects selected from the farm pack here.
  - These are not final WorkMap office assets.
- `apps/web/public/assets/status/`
  - Put status rings, dots, and icons here.
- `apps/web/public/assets/dashboard/`
  - Put dashboard icons and illustrations here.

## License Note

Commercial art assets should stay out of public repositories unless the license explicitly allows redistribution.
